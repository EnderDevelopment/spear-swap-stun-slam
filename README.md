# Spear Stun Slam Mod

A Minecraft mod that enhances combat with spear swapping and automatic stun slamming. It allows players to swap spears with a key press and automatically stun slam players holding shields when the crosshair is on them. The mod is compatible with Vulkan mod.

## Install

1. Install the Fabric loader for Minecraft 1.20.4.
2. Download the SpearStunSlam mod jar.
3. Place the jar file in the mods folder.

## Use

1. Hold the B key to swap spears.
2. Aim at a player holding a shield to automatically stun slam them.
